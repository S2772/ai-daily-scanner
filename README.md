# AI热点日报系统

一个本地化的AI热点收集、分析和机会挖掘系统，具有现代化的Web界面。

## 系统特点

### 🎨 现代化UI设计
- **苹果风格界面**：简约、优雅的设计风格
- **响应式布局**：支持桌面和移动设备
- **深色模式准备**：为夜间使用优化
- **平滑动画**：流畅的用户交互体验

### 🔄 完整交互功能
- **多视图切换**：网格视图和列表视图
- **智能筛选**：按分类、标签、关键词筛选
- **实时搜索**：快速查找热点和机会
- **日期选择**：查看不同日期的数据

### 📊 数据分析功能
- **数据统计**：实时显示热点、机会、笔记数量
- **趋势分析**：创新度和商业潜力趋势
- **摘要分析**：自动生成每日分析报告
- **数据可视化**：热点分布图表（待集成）

### 📝 笔记管理系统
- **可编辑笔记**：完整的笔记创建、编辑、删除功能
- **标签管理**：为笔记添加和管理标签
- **热点关联**：笔记与热点/机会关联
- **历史记录**：查看和管理所有笔记

### 📤 数据导出功能
- **CSV导出**：导出热点、机会、笔记数据
- **批量操作**：支持批量导出和分析

## 系统架构

### 前端技术栈
- **HTML5**：语义化标签，现代化结构
- **CSS3**：Flexbox/Grid布局，CSS变量，动画
- **JavaScript**：原生ES6+，模块化设计
- **Font Awesome**：图标库

### 后端技术栈
- **Python Flask**：轻量级Web框架
- **SQLite**：嵌入式数据库
- **RESTful API**：前后端分离架构

### 数据流程
1. **数据收集**：爬虫脚本收集AI热点
2. **数据处理**：分析、评分、机会挖掘
3. **数据存储**：SQLite数据库存储
4. **数据展示**：Web界面展示和交互
5. **用户交互**：笔记、筛选、分析

## 快速开始

### 1. 环境要求
- Python 3.7+
- Flask 2.0+
- SQLite3

### 2. 安装依赖
```bash
pip install flask
```

### 2.1 配置 AI 环境变量
在项目根目录创建 `.env`，可参考 `.env.example`：

```bash
cp .env.example .env
```

至少需要设置：

```bash
AI_API_KEY=your_real_api_key_here
```

说明：
- 不要把真实 `AI_API_KEY` 写进代码或提交到 Git
- `start.sh` 会自动加载根目录 `.env`

### 3. 启动系统
```bash
# 方法1: 使用启动脚本（推荐）
./start.sh

# 方法2: 直接运行
python webapp.py
```

### 4. 访问系统
打开浏览器访问：前端 `http://127.0.0.1:3000/`（主UI），后端 `http://127.0.0.1:6003/`

### 5. 填充数据
```bash
# 运行爬虫脚本收集数据
python scraper.py
```

## API接口

### 数据接口
- `GET /api/data` - 获取所有数据
- `GET /api/hotspots` - 获取热点数据
- `GET /api/opportunities` - 获取机会数据
- `GET /api/notes` - 获取笔记数据
- `GET /api/stats` - 获取统计数据

### 操作接口
- `POST /api/collect` - 触发热点收集
- `POST /api/notes` - 创建笔记
- `PUT /api/notes/<id>` - 更新笔记
- `DELETE /api/notes/<id>` - 删除笔记

### 导出接口
- `GET /api/export/hotspots` - 导出热点数据
- `GET /api/export/opportunities` - 导出机会数据
- `GET /api/export/notes` - 导出笔记数据

## 故障排除

### 常见问题
1. **页面无法访问**
   - 检查服务器是否启动：`ps aux | grep python`
   - 检查端口是否被占用：`lsof -i :5000`
   - 检查防火墙设置

2. **没有数据展示**
   - 检查数据库文件是否存在
   - 运行爬虫脚本收集数据
   - 检查API接口是否正常

3. **样式或脚本不生效**
   - 清除浏览器缓存
   - 检查文件路径是否正确
   - 查看浏览器开发者工具控制台

4. **笔记功能异常**
   - 检查数据库连接
   - 查看API响应状态
   - 检查JavaScript错误

### 日志查看

```bash
python webapp.py 2>&1 | tee error.log
```
